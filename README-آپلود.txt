فایل‌هایی که باید در ریپو باشند (همه را یکجا آپلود کنید):

  1. index.html              ← صفحه اصلی (ظاهر‌خوان از قبل داخلش گذاشته شده)
  2. appearance.json         ← تنظیمات ظاهر (تیتر، تب، رنگ، نسخه)
  3. stock.csv               ← موجودی
  4. stock_update.json       ← پشتیبان موجودی
  5. GUIDE-FA.html           ← راهنمای موجودی
  6. GUIDE-APPEARANCE-FA.html← راهنمای ظاهر
  7. admin-appearance.php    ← اختیاری (فقط اگر هاست PHP دارید)
  8. appearance-loader.js    ← اختیاری (چون داخل index.html هم هست)

──────────────────────────────────────────────────────────────
اولین بار (یک‌بار برای همیشه)
──────────────────────────────────────────────────────────────
1. بروید به: https://github.com/reisimehdi-bot/asa-atras
2. Add file → Upload files
3. همه فایل‌های بالا را بکشید و رها کنید
4. پیام بنویسید: «نسخه اولیه با ظاهر آنلاین»
5. Commit changes
6. ۳۰–۶۰ ثانیه صبر کنید
7. صفحه را با Ctrl+F5 باز کنید و تست کنید

──────────────────────────────────────────────────────────────
هر روز فقط موجودی عوض شد
──────────────────────────────────────────────────────────────
→ فقط stock.csv را در گیت‌هاب Edit کنید و عدد را عوض کنید → Commit

──────────────────────────────────────────────────────────────
فقط ظاهر (تیتر / رنگ / تب) عوض شد
──────────────────────────────────────────────────────────────
→ فقط appearance.json را Edit کنید
→ فیلد "version" را کمی بالا ببرید (مثلاً 2026.09.24.1 → 2026.09.24.2)
→ Commit
→ کاربران با رفرش ظاهر جدید را می‌گیرند

──────────────────────────────────────────────────────────────
ساختار صفحه عوض شد (تب جدید، ستون جدید، باگ فیکس بزرگ)
──────────────────────────────────────────────────────────────
1. index.html جدید را آپلود/جایگزین کنید
2. داخل appearance.json فیلد version را بالا ببرید
3. (اختیاری) forceUpdate را true کنید تا بنر حتماً نشان داده شود
4. Commit
→ کاربران بنر «دانلود نسخه جدید» می‌بینند

──────────────────────────────────────────────────────────────
نکته راحت برای مبتدی
──────────────────────────────────────────────────────────────
برای عوض کردن ظاهر نیازی به برنامه نیست:
  • در گیت‌هاب روی appearance.json کلیک کنید
  • مداد (Edit) را بزنید
  • متن یا کد رنگ را عوض کنید
  • Commit changes
