راهنمای کامل تغییر ظاهر + همگام‌سازی برای کاربران

شما می‌خواهید تیتر هدر، تعداد/نام تب‌ها، رنگ‌ها و متن‌ها را عوض کنید و همین تغییرات برای کاربران آنلاین و آفلاین هم اعمال شود (یا حداقل از آن‌ها خواسته شود نسخهٔ جدید را بگیرند).

خلاصهٔ راه‌حل پیشنهادی (بهترین و سبک‌ترین):
  • یک فایل کوچک به نام appearance.json روی گیت‌هاب (یا سرور) نگه دارید.
  • در index.html یک اسکریپت کوتاه (appearance-loader.js) بگذارید که این فایل را بخواند و رنگ/تیتر/تب را اعمال کند.
  • هر وقت ظاهر را عوض کردید، فقط appearance.json را ویرایش و Commit کنید — کاربران با رفرش ظاهر جدید را می‌بینند.
  • اگر خودِ ساختار HTML عوض شد (تب جدید، ستون جدید و …)، index.html را هم آپلود کنید و شمارهٔ version را بالا ببرید تا بنر «دانلود نسخه جدید» نشان داده شود.

۱. فایل‌هایی که باید داشته باشید

فایلنقش
appearance.jsonتنظیمات ظاهر (تیتر، رنگ، تب، نسخه)
appearance-loader.jsکدی که داخل صفحه ظاهر را از اینترنت می‌خواند
admin-appearance.phpاختیاری — پنل ساده روی هاست PHP برای ویرایش راحت‌تر
index.htmlهمان کاتالوگ فعلی (باید loader را به آن اضافه کنید)
stock.csv / stock_update.jsonموجودی (مثل قبل)

همهٔ این فایل‌ها در پوشهٔ همین راهنما قرار دارند تا دانلود کنید.

۲. قدم‌به‌قدم: وصل کردن ظاهر آنلاین به index.html

قدم ۱ — آپلود appearance.json

  1. به ریپوی گیت‌هاب بروید:
    https://github.com/reisimehdi-bot/asa-atras
  2. Add file → Upload files
  3. فایل appearance.json را آپلود و Commit کنید.

آدرس خام آن این می‌شود:

https://raw.githubusercontent.com/reisimehdi-bot/asa-atras/main/appearance.json
خبر خوب: در فایل index.html که برایتان آماده شده، اسکریپت ظاهر از قبل داخلش گذاشته شده. نیازی به کپی دستی نیست — فقط همین index.html را آپلود کنید.

قدم ۲ — اضافه کردن loader به index.html (اگر از فایل قدیمی استفاده می‌کنید)

دو روش ساده:

روش الف (پیشنهادی): محتوای فایل appearance-loader.js را کپی کنید و قبل از آخرین تگ </body> در index.html بچسبانید، داخل یک تگ اسکریپت:

<script>
  /* اینجا کل محتوای appearance-loader.js را بچسبانید */
</script>
</body>

روش ب: اگر فایل جدا می‌خواهید نگه دارید:

<script src="appearance-loader.js"></script>
</body>

(در این حالت هر دو فایل باید در همان پوشهٔ سایت باشند.)

مهم: داخل appearance-loader.js این دو مقدار را چک کنید:
  • APPEARANCE_URL → باید همان آدرس raw گیت‌هاب شما باشد.
  • LOCAL_VERSION → نسخهٔ فعلی همین فایل HTML (مثلاً 2026.09.24.1). هر وقت index.html را عوض کردید این را هم بالا ببرید.

قدم ۳ — تست

  1. صفحه را با اینترنت باز کنید.
  2. در کنسول مرورگر (F12 → Console) اگر خطایی نبود، ظاهر از JSON خوانده شده.
  3. در appearance.json مثلاً clkTitle را عوض کنید، Commit کنید، ۳۰ ثانیه صبر کنید، صفحه را رفرش کنید → متن عوض می‌شود.

۳. چه چیزهایی با appearance.json عوض می‌شوند؟

کلیداثر
versionشماره نسخه. اگر با نسخهٔ فایل HTML فرق کند → بنر به‌روزرسانی
forceUpdateاگر true باشد همیشه بنر نشان داده می‌شود
messageمتن بنر
downloadUrlلینک دکمه «دانلود نسخه جدید»
titleعنوان تب مرورگر و صفحه
clkTitleمتن زیر ساعت در هدر
brandName / brandUrlنام و لینک برند
footerTextمتن پایین صفحه
tabs.search / tabs.listtrue/false — نمایش یا مخفی کردن تب
tabLabelsمتن روی دکمه‌های تب
colorsرنگ‌های اصلی (همان‌هایی که در تنظیمات ⚙ صفحه هم هستند)
رنگ‌های کاربر که در مرورگر خودش با دکمه ⚙ ذخیره کرده (localStorage) اولویت محلی دارد. اگر می‌خواهید همیشه رنگ سرور غالب باشد، می‌توانید در loader بعد از applyColors کلید localStorage رنگ‌ها را پاک کنید — فعلاً عمداً رنگ شخصی کاربر حفظ می‌شود.

۴. دو حالت به‌روزرسانی ظاهر

حالتچه کار کنید؟کاربر چه می‌بیند؟
الف) فقط متن/رنگ/تب فقط appearance.json را Edit و Commit کنید. version را کمی بالا ببرید (مثلاً .1 → .2). با رفرش صفحه، ظاهر جدید اعمال می‌شود. اگر نسخه فرق کند، بنر کوچک پایین صفحه هم می‌آید.
ب) تغییر ساختار صفحه
(ستون جدید، تب جدید، باگ فیکس بزرگ)		 index.html جدید + appearance.json با version بالاتر و در صورت نیاز forceUpdate: true را آپلود کنید. بنر «نسخه جدید» نشان داده می‌شود و لینک دانلود/باز کردن نسخهٔ آنلاین می‌دهد. فایل آفلاین قدیمی تا وقتی دانلود نکند همان می‌ماند.

۵. کاربران آفلاین چه می‌شود؟

  • فایل index.html به‌تنهایی کار می‌کند (دادهٔ داخلی + موجودی کش‌شده).
  • آخرین ظاهر موفق از اینترنت در localStorage ذخیره می‌شود؛ دفعهٔ بعد آفلاین هم همان ظاهر اعمال می‌شود.
  • اگر version سرور بالاتر باشد، وقتی آنلاین شد بنر می‌آید و می‌گوید نسخهٔ جدید را دانلود/رفرش کند.

برای توزیع آفلاین: همان index.html را به کاربران بدهید (واتساپ، فلش، …). وقتی آنلاین شدند، ظاهر و موجودی به‌روز می‌شود.

۶. ویرایش ظاهر بدون سر و کله با من — ابزارهای پیشنهادی برای مبتدی

بهترین انتخاب سبک و رایگان برای مبتدی:
  • ویرایشگر گیت‌هاب در مرورگر (ساده‌ترین): فایل appearance.json را در سایت گیت‌هاب باز کنید → مداد Edit → اعداد رنگ یا متن را عوض کنید → Commit. هیچ برنامه‌ای نصب نمی‌خواهد.
  • Notepad++ (ویندوز، خیلی سبک): فقط برای دیدن و ویرایش JSON/HTML. نصب چند مگابایتی، بدون پیچیدگی.
  • VS Code (رایگان، کمی سنگین‌تر ولی عالی): اگر بخواهید بعداً HTML را هم دست بزنید. افزونهٔ Live Server برای پیش‌نمایش فوری.

برای فقط رنگ‌ها داخل خود صفحه: دکمه ⚙ بالا-چپ صفحه را بزنید — رنگ‌ها را زنده عوض می‌کند و در مرورگر شما ذخیره می‌شود. این رنگ‌ها فقط مال همان کاربر است؛ برای همه باید در appearance.json بگذارید.

برنامه‌های آنلاین بدون نصب:

  • jsoneditoronline.org — ظاهر JSON را درختی و راحت ویرایش کنید، بعد کپی و در گیت‌هاب Paste کنید.
  • رنگ‌ها: هر سایت Color Picker (مثلاً search: color picker) → کد هگز (#0f3d5c) را کپی کنید.

پیشنهاد عملی روزانه:

  1. می‌خواهید فقط رنگ یا تیتر عوض شود → appearance.json را در گیت‌هاب Edit کنید (۱ دقیقه).
  2. می‌خواهید ساختار عوض شود → فایل HTML جدید را از کسی که می‌سازد بگیرید، آپلود کنید، version را بالا ببرید.

۷. اگر هاست PHP دارید (اختیاری)

  1. فایل admin-appearance.php و یک کپی از appearance.json را در یک پوشه روی هاست بگذارید.
  2. رمز داخل فایل PHP را عوض کنید ($PASSWORD).
  3. با مرورگر باز کنید، وارد شوید، فرم را پر کنید، ذخیره کنید.
  4. فایل JSON ساخته‌شده را دانلود و در گیت‌هاب جایگزین کنید (یا اگر هاستتان همان جایی است که سایت را سرو می‌کند، مستقیم لینک raw را به همان فایل بدهید).

بدون PHP هم کاملاً کار می‌کند — PHP فقط فرم راحت‌تر می‌سازد.

۸. چک‌لیست سریع وقتی ظاهر را عوض کردید

  1. در appearance.json فیلد version را افزایش دهید.
  2. اگر HTML هم عوض شد: LOCAL_VERSION داخل loader را با همان شماره هماهنگ کنید و index.html را آپلود کنید.
  3. Commit در گیت‌هاب.
  4. ۳۰–۶۰ ثانیه صبر کنید.
  5. صفحه را با Ctrl+F5 (یا در موبایل سخت‌رفرش) باز کنید و تست کنید.

۱۰. خلاصه خیلی کوتاه

  • ظاهر روزمره (تیتر، رنگ، تب) → فقط appearance.json را در گیت‌هاب Edit کنید.
  • ساختار صفحه عوض شد → index.html جدید + بالا بردن version تا کاربران بنر دانلود ببینند.
  • آفلاین → همان HTML کار می‌کند؛ وقتی آنلاین شد ظاهر و موجودی را می‌گیرد.
  • بدون مزاحم کردن من → از ویرایشگر گیت‌هاب یا Notepad++ / jsoneditoronline برای JSON استفاده کنید؛ رنگ‌های شخصی هم از دکمه ⚙ داخل خود صفحه.
