۳. اولین آپلود روی گیت‌هاب

  1. ریپوی Public بسازید: نام پیشنهادی asa-atras با کاربر reisimehdi-bot
  2. Add file → Upload files
  3. همه محتویات این پوشه را آپلود کنید (از جمله پوشه .github و music و photos)
  4. Commit کنید
  5. Settings → Pages → Source: GitHub Actions
  6. تب Actions را چک کنید تا سبز شود
  7. سایت: https://reisimehdi-bot.github.io/asa-atras/

اگر نام کاربری یا ریپو فرق دارد، در این فایل‌ها جستجو کنید و آدرس را عوض کنید:

  • index.html (چند جا: stock، appearance، meta)
  • appearance.json (downloadUrl و brandUrl)
  • appearance-loader.js

۵. عوض کردن ساختار و جای المان‌های صفحه

برای مبتدی: اول فقط متن و رنگ را از appearance.json عوض کنید. وقتی راحت‌تر شدید، سراغ HTML بروید.

بخش‌های مهم داخل index.html

چی را می‌خواهید عوض کنید؟کجا را پیدا کنید؟
نام برند در هدرجستجو: brand-name یا از appearance.json فیلد brandName
تب‌ها (جستجو / فهرست)جستجو: class="tabs" و appearance.json → tabs
رنگ‌هاappearance.json → colors یا دکمه ⚙ در صفحه
دکمه میزیتوجستجو: btn-row-mizito و تابع sendToMizito
نوار موسیقیجستجو: musicBar و initMusicPlayer
پیش‌نمایش عکس میزیتو (۷ ثانیه)جستجو: showMizitoPhotoPreview
آدرس موجودی از گیت‌هابجستجو: GITHUB_STOCK_CSV_URL

در VS Code یا Notepad++ با Ctrl+F همان کلمات را جستجو کنید.

نکته امن

  • قبل از تغییر بزرگ، یک کپی از index.html نگه دارید.
  • بعد از تغییر ساختار، LOCAL_VERSION داخل index و version داخل appearance.json را یکی کنید و بالا ببرید تا کاربران بنر به‌روزرسانی ببینند.

۶. موسیقی

  1. فایل‌های MP3 را در پوشه music/ بگذارید (ترجیحاً زیر ۵ مگ هر فایل).
  2. در appearance.json:
"music": [
  { "name": "آرام ۱", "file": "aram1.mp3" },
  { "name": "آرام ۲", "file": "relax2.mp3" }
]
  1. version را بالا ببرید و Commit کنید.
  2. در صفحه نوار پایین ظاهر می‌شود: انتخاب آهنگ + پخش + صدا.

اگر music خالی باشد، نوار نشان داده نمی‌شود.

۷. عکس کالا و پیش‌نمایش میزیتو

  • عکس را در photos/ با نام دقیق کد کالا بگذارید:
    photos/2000-CAP-0001.jpg
  • وقتی کاربر «ارسال به میزیتو» را بزند:
    • متن کپی می‌شود و میزیتو باز می‌شود
    • کارت کوچک عکس/عنوان برای ۷ ثانیه بالای دکمه می‌آید
    • کلیک‌ها مسدود نمی‌شوند
  • اگر عکس نباشد، فقط آیکون و عنوان نشان داده می‌شود.

۸. GitHub Actions

فایل .github/workflows/deploy-pages.yml هر بار بعد از Commit روی main سایت را روی Pages منتشر می‌کند.

  1. Settings → Pages → Source = GitHub Actions
  2. Settings → Actions → Allow all + Read and write
  3. بعد از Commit حدود ۱–۲ دقیقه صبر کنید

جزئیات بیشتر: GITHUB-ACTIONS-راهنما.txt
