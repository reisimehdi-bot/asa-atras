پوشه موسیقی (music)
====================
فایل‌های صوتی را همین‌جا آپلود کنید.

فایل پیشنهادی فعلی (appearance.json):
  music/batman-theme.mp3   ← تم بی‌کلام بت‌من

نام فایل باید دقیقاً با فیلد "file" در appearance.json یکی باشد.

مثال appearance.json:
  "music": [
    { "name": "تم بت‌من (بی‌کلام)", "file": "batman-theme.mp3" }
  ]

فرمت: MP3 (پیشنهادی) · OGG · M4A
حجم: ترجیحاً زیر ۵ مگابایت

نکته حقوقی:
  تم اصلی بت‌من اثر دارای حق‌تألیف است.
  فقط فایلی را آپلود کنید که مجوز استفاده دارید
  (نسخه رایگان/کاور مجاز یا خریداری‌شده).

مسیر آپلود در گیت‌هاب:
  ریپو → پوشه music → Upload files → Commit
  سپس version در appearance.json را بالا ببرید.
