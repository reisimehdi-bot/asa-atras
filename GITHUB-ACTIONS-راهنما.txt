══════════════════════════════════════════════════════════════
  راهنمای GitHub Actions — انتشار خودکار سایت
══════════════════════════════════════════════════════════════

هدف:
  هر بار که فایل‌ها را در گیت‌هاب Commit کنید،
  سایت به‌صورت خودکار روی GitHub Pages به‌روز شود.
  نیازی به «Upload دستی» جداگانه نیست — همان Commit کافی است.

──────────────────────────────────────────────────────────────
قدم ۱ — ساخت ریپو (اگر هنوز نساخته‌اید)
──────────────────────────────────────────────────────────────
1. https://github.com/new
2. نام: asa-atras
3. Public را انتخاب کنید
4. Create repository

──────────────────────────────────────────────────────────────
قدم ۲ — آپلود فایل‌ها + فایل Action
──────────────────────────────────────────────────────────────
باید این ساختار در ریپو باشد:

  asa-atras/
  ├── index.html
  ├── appearance.json
  ├── stock.csv
  ├── stock_update.json
  ├── ... (سایر فایل‌ها)
  └── .github/
      └── workflows/
          └── deploy-pages.yml

روش ساده با مرورگر:
  1. اول همه فایل‌های معمولی را Upload و Commit کنید.
  2. بعد برای ساخت پوشه Action:
     - Add file → Create new file
     - مسیر را این‌طور بنویسید:
       .github/workflows/deploy-pages.yml
     - محتوای فایل deploy-pages.yml را Paste کنید
     - Commit کنید

──────────────────────────────────────────────────────────────
قدم ۳ — روشن کردن GitHub Pages (یک‌بار)
──────────────────────────────────────────────────────────────
1. وارد ریپو شوید
2. Settings → Pages
3. بخش Build and deployment:
   - Source:  GitHub Actions   ← مهم (نه Deploy from a branch)
4. Save

اگر قبلاً «Deploy from a branch» بود، آن را به GitHub Actions عوض کنید.

──────────────────────────────────────────────────────────────
قدم ۴ — اولین اجرا
──────────────────────────────────────────────────────────────
1. تب Actions را باز کنید
2. باید workflow به نام «Deploy to GitHub Pages» دیده شود
3. اگر هنوز اجرا نشده: یک تغییر کوچک در README بدهید و Commit کنید
   یا از workflow_dispatch (Run workflow) دستی اجرا کنید
4. وقتی سبز شد (Success)، سایت آماده است:

   https://reisimehdi-bot.github.io/asa-atras/

──────────────────────────────────────────────────────────────
از این به بعد چه کار کنید؟
──────────────────────────────────────────────────────────────
• فقط موجودی عوض شد → stock.csv را Edit → Commit
• فقط ظاهر عوض شد → appearance.json را Edit → Commit
• صفحه عوض شد → index.html را Upload → Commit

بعد از هر Commit حدود ۱–۲ دقیقه صبر کنید؛
Actions خودش سایت را منتشر می‌کند. نیازی به کار اضافه نیست.

──────────────────────────────────────────────────────────────
اگر Action خطا داد
──────────────────────────────────────────────────────────────
• Settings → Actions → General
  - Actions permissions: Allow all actions
  - Workflow permissions: Read and write permissions
• Settings → Pages → Source باید GitHub Actions باشد
• ریپو باید Public باشد (برای Pages رایگان)

──────────────────────────────────────────────────────────────
نکته درباره raw فایل‌ها (stock و appearance)
──────────────────────────────────────────────────────────────
آدرس‌های raw مثل:
  https://raw.githubusercontent.com/reisimehdi-bot/asa-atras/main/stock.csv
بلافاصله بعد از Commit در دسترس‌اند و به Pages وابسته نیستند.
صفحه index.html از همین raw برای موجودی و ظاهر استفاده می‌کند.
