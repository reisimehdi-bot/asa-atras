الف) فقط موجودیفقط عدد موجودی چند کالافقط stock.csv
ب) کالای جدید یا تغییر کاتالوگردیف جدید، عنوان، کد، گروه و ...باید index.html را هم به‌روز کنید


حالت الف) فقط تغییر موجودی (کار روزانه — حدود ۱ دقیقه)


این کار را می‌توانید با گوشی اندروید یا کامپیوتر انجام دهید.


روش ۱: با گوشی اندروید + اپلیکیشن GitHub


قدم ۱ — نصب اپ

  1. از Google Play اپلیکیشن GitHub را نصب کنید.
  2. وارد حساب گیت‌هاب خود شوید.

قدم ۲ — باز کردن ریپو

  1. داخل اپ، روی ذره‌بین (Search) بزنید.
  2. بنویسید: reisimehdi-bot
  3. ریپوی reisimehdi-bot/asa-atras را باز کنید.

قدم ۳ — باز کردن فایل موجودی

  1. فایل stock.csv را پیدا کنید و باز کنید.
  2. گوشه بالا روی آیکون مداد (Edit) بزنید.

قدم ۴ — ویرایش عدد موجودی

فایل شبیه این است:


``

code,stock

2000-CAP-0001,20

2000-CAP-0002,3175

2000-CAP-0003,0

`


  • ستون اول = کد کالا (دست نزنید)
  • ستون دوم = موجودی (همین را عوض کنید)

مثال: اگر موجودی 2000-CAP-0001 از ۲۰ به ۱۵ رسید، بنویسید:


`

2000-CAP-0001,15

`


قدم ۵ — ذخیره و ارسال

  1. پایین صفحه روی Commit changes بزنید.
  2. یک توضیح کوتاه بنویسید (مثلاً: آپدیت موجودی ۲۱ شهریور).
  3. دوباره Commit changes را بزنید.

قدم ۶ — صبر کنید

۳۰ تا ۶۰ ثانیه صبر کنید تا سایت آدرس raw را به‌روز کند. بعد صفحه جستجو را Refresh کنید.



روش ۲: با مرورگر گوشی یا کامپیوتر (سایت گیت‌هاب)


  1. بروید به:

https://github.com/reisimehdi-bot/asa-atras

  1. فایل stock.csv را باز کنید.
  2. روی آیکون مداد (Edit this file) کلیک کنید.
  3. اعداد ستون stock را عوض کنید.
  4. پایین صفحه دکمه سبز Commit changes را بزنید.
  5. ۳۰–۶۰ ثانیه صبر کنید و صفحه سایت قطعات را رفرش کنید.


روش ۳: با Google Sheets روی گوشی (راحت‌تر برای تعداد زیاد)


  1. فایل stock.csv را از گیت‌هاب Download کنید.
  2. با Google Sheets باز کنید.
  3. ستون موجودی را ویرایش کنید.
  4. از منو: File → Download → Comma-Separated Values (.csv)
  5. فایل دانلودشده را دوباره در گیت‌هاب آپلود کنید:

- وارد ریپو شوید

- روی stock.csv کلیک کنید

- آیکون سطل زباله (حذف) بزنید و Commit کنید

- بعد Add file → Upload files و فایل جدید را بکشید و Commit کنید


یا ساده‌تر: همان Edit در گیت‌هاب و Paste کردن محتوای CSV جدید.



حالت ب) اضافه شدن کالای جدید یا تغییر کل صفحه


وقتی کالای جدید اضافه می‌شود، فقط تغییر stock.csv کافی نیست.

باید فایل index.html (کاتالوگ کامل) هم به‌روز شود.


چه کسی این کار را انجام می‌دهد؟

معمولاً کسی که فایل کامل index.html جدید را می‌سازد (مثلاً از خروجی سیستم انبار یا فایلی که قبلاً آماده شده).


قدم‌به‌قدم روی کامپیوتر (پیشنهادی)


۱. فایل جدید را آماده کنید

  • فایل index.html جدید (با ردیف‌های اضافه‌شده) را داشته باشید.
  • در صورت نیاز stock.csv و stock_update.json هم از روی همان داده ساخته شود.

۲. ورود به گیت‌هاب

آدرس:

https://github.com/reisimehdi-bot/asa-atras


۳. آپلود فایل‌های جدید

  1. روی Add file → Upload files کلیک کنید.
  2. فایل‌های جدید را بکشید و رها کنید:

- index.html

- stock.csv

- stock_update.json (اختیاری)

  1. پایین صفحه یک پیام بنویسید (مثلاً: افزودن کالاهای جدید).
  2. دکمه سبز Commit changes را بزنید.

اگر فایلی از قبل وجود دارد، گیت‌هاب می‌پرسد آیا جایگزین شود — Replace را انتخاب کنید.


۴. بررسی

  1. چند دقیقه صبر کنید.
  2. صفحه سایت قطعات را با Ctrl+F5 (یا در موبایل سخت‌رفرش) باز کنید.
  3. کالای جدید را جستجو کنید.


قدم‌به‌قدم روی گوشی اندروید (اپ GitHub)


  1. اپ GitHub را باز کنید و وارد ریپو شوید.
  2. منوی ⋯ (سه نقطه) → Upload files (اگر بود) یا از مرورگر موبایل استفاده کنید.
  3. روی گوشی معمولاً آپلود چند فایل بزرگ با مرورگر Chrome راحت‌تر است:

- Chrome را باز کنید

- به آدرس ریپو بروید

- Add file → Upload files

- فایل‌ها را از پوشه Downloads انتخاب کنید

- Commit کنید



نکات مهم


  1. کد کالا باید دقیقاً مثل قبل باشد (مثلاً 2000-CAP-0001). اگر یک حرف اشتباه باشد، موجودی روی سایت نمی‌نشیند.
  2. فایل CSV را همیشه با کدگذاری UTF-8 ذخیره کنید تا حروف فارسی خراب نشود.
  3. بعد از هر Commit، ۳۰ تا ۶۰ ثانیه صبر کنید؛ آدرس‌های raw کمی تأخیر دارند.
  4. ریپو باید Public باشد تا سایت بدون رمز بتواند فایل‌ها را بخواند.
  5. کالای جدید فقط با CSV اضافه نمی‌شود؛ حتماً index.html باید ردیف آن کالا را داشته باشد.
